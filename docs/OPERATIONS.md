# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。

## 季度退租结算

1. 打开 `/settlement`，选择 `q1` 样例或上传退租来源 CSV，先点“预览裁决”（不入库）。
2. 查看三部门返还清单与“共用保留/阻断原因”：链未退完的快照留在共用保留，闭合链只在归属部门结算一次。
3. 预览对账 `balanced=true` 后点“执行结算期次”，填写复核意见并“签发”；签发后该期冻结。
4. 下一季度上传增量来源（如 `q2`）：历史已结算的对象/快照自动跳过，退完的共享链在本期只结算一次。
5. 若返回 `SETTLEMENT_BLOCKED`，按 `details.reasons` 修复来源后重传；阻断批次不写库，旧版已签发清单保留。
6. 同一来源重跑不产生新期次；通过“下载结算证据”保存 `settlement-evidence/1` 交接。
